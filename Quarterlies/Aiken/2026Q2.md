# Community changes (last committer addition)
changelog: |
  - Released compiler [v1.1.22 on 15 May](https://github.com/aiken-lang/aiken/releases/tag/v1.1.22). This shipped the blueprint `--include-all-types` flag, `aiken test` alias and benchmark improvements developed in Q1. It also improved test diagnostics for continuation-passing code, compiler optimisations, language-server import suggestions and parser/code-generation robustness.
  - Released compiler [v1.1.23 on 26 June](https://github.com/aiken-lang/aiken/releases/tag/v1.1.23), adding protocol-aware phase-two evaluation and support for Plutus V3 PV11 cost models. Correctness fixes preserved typed `expect` validation for unused bindings, avoided decoder-name collisions and handled oversized decorator values without a compiler panic. These are evaluator capabilities, not a claim about mainnet activation dates.
  - Released standard library [v3.1.0 on 24 April](https://github.com/aiken-lang/stdlib/releases/tag/v3.1.0), expanding collection and asset operations, adding BLS constants and forcible `expect_*` helpers, and optimising list, dictionary, pairs and asset functions.
  - Published a clearer [first-contribution workflow](https://github.com/aiken-lang/aiken/commit/7a0a8e2b70f58354e157ca1cd9a53876421eeea1) in June. It gives contributors a concrete path from selecting work through local checks and pull-request submission.
