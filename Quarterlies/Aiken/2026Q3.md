# Community changes (last committer addition)
changelog: |
  - Released compiler [v1.1.24 on 26 September](https://github.com/aiken-lang/aiken/releases/tag/v1.1.24), adding first-class UPLC `Value` support, Value literals and value reification. The release exposed the associated value builtins and added conformance coverage.
  - Improved compiler and evaluator performance, including reduced memory and processing costs during testing and optimisation, and faster evaluation of large `Data` values when builtin cost functions are constant. 
  - Fixed opaque-type conversion checks, empty-list type ambiguity, constant-folding crashes, BLS multi-scalar argument conversion and constant-evaluation error handling.
  - Released standard library [v4.0.0 on 26 September](https://github.com/aiken-lang/stdlib/releases/tag/v4.0.0), adding the `cardano/value` module and conversions between builtin values and assets. Breaking changes renamed the previous `Value` type to `Assets` and corrected script-purpose comparison to match ledger ordering. BLS12-381 and collection helpers were also extended.
  - Updated documentation for the new Value builtin and [refreshed contribution guidance](https://github.com/aiken-lang/aiken/commit/d2200d6d521618aee5d318c01236b42adf1a90ed). Distribution changed too: [Intel macOS release/build targets were removed on 22 September](https://github.com/aiken-lang/aiken/commit/45b49a48d0ab8343d7e198e32aeae8f4bcbe0316), and the v1.1.24 release lists Apple Silicon rather than an Intel macOS binary.
  - Submitted past due quarterly documents, caught up and using AI to simplify the task. Awaiting Board to share MC regulations document for MCs.
