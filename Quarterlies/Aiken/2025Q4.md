# Community changes (last committer addition)
changelog: |
  - Released standard library [v3.0.0 on 22 October](https://github.com/aiken-lang/stdlib/releases/tag/v3.0.0). It added constrained-field arithmetic modules (`int224` and `int256`), BLS12-381 pairing support, collection helpers and NFT inspection functions. The interval implementation was revised and retested, resolving the work that had held up release in Q3.
  - The standard library's major-version changes included revised dictionary/assets callback APIs and an integer-specific `Interval` type. These were documented as breaking changes for consumers to assess during upgrades.
  - Released compiler [v1.1.21 on 12 December](https://github.com/aiken-lang/aiken/releases/tag/v1.1.21), adding custom error traces for `expect` and improving language-server diagnostics. Fixes addressed generic-type and code-generation crashes, blueprint encoding and references, explicit-blueprint simulation, and credential handling in Plutus V1/V2 execution.
  - Released standard library [v2.2.1 on 16 December](https://github.com/aiken-lang/stdlib/releases/tag/v2.2.1), exposing the `Foldl2` type and adding a warning for `foldl2` on the older release line.
  - Continued participation in PRAGMA open coding hours.
